Add Sync tracks, Voice wildcard and music trim to Remove pauses

Remove pauses only had two kinds of audio: speech (cut, and decides where
the silences are) and everything else (kept whole like a music bed). Game
sound that has to stay matched to the picture fit neither: as speech, its
random sound events blocked the cuts; as a bed, it drifted out of sync.

- Add a third kind: tracks whose name contains Sync (Main Sync, Jimmy Sync,
  plus legacy Game/Gameplay/Follow/Linked/Lockstep) are cut with Main but
  never used to find silences, and are not treated as music.
- New projects now start with Voice any, Main Sync and Music. Sound effects
  is no longer a default track (it is still created on demand).
- Remove pauses now shortens music that runs past the end of the Main
  track. Music is still never cut up.
- Tests updated for the renamed default tracks, and new tests added.
