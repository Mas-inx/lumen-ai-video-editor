## Lumen 1.2: Copilot meets your MCP servers

### Copilot uses your MCP servers

Every MCP server you connect now adds its tools to the Copilot, and Claude Code and Codex get them through Lumen too. Each server has a switch for this, on by default. A tool its server marks as destructive asks you before it runs.

### GS Cinematic Studio

Direct GTA V cinematics in a FiveM game from the Copilot. **GS Cinematic Studio** is in the MCP catalogue. It lets the Copilot:

- open projects and stage scenes;
- use the in-game AI Director, or Auto-Direct a whole clip from one prompt;
- fix the cameras and look through a shot;
- take screenshots of the game;
- render video and drop it straight onto your timeline.

To connect, enter your FiveM server's address and its `gcs_mcp_token`. A director in the game turns remote control on with `/studio_remote on`, and their game does the filming.

### Also

- Plain `http://` MCP servers now work on your local network (10.x, 172.16–31.x, 192.168.x, Tailscale, `.local`) as well as on this computer. Servers on the internet still need https.
- Studio tools stay out of the Generate panel; the Copilot runs them.

Lumen 1.1 and later update themselves: restart Lumen once this release is out. Lumen 1.0.x needs this installer once.
