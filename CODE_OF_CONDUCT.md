# Code of conduct

Lumen follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, assume good intent, and give feedback about the work, not the person. Harassment, insults and discrimination aren't tolerated anywhere in the project — issues, pull requests, discussions or anywhere you represent it.

If something makes you uncomfortable, contact the maintainers privately through GitHub (a private security advisory works for anything sensitive). Reports are handled confidentially.
